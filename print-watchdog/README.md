# print-watchdog

Наблюдение за печатью: раз в несколько секунд забирает кадр с камеры каждого принтера,
прогоняет его через детектор дефектов и, если видит спагетти, шлёт уведомление в Telegram.

Состоит из двух частей:

- `watchdog.py` — сама служба. Список принтеров и пороги берёт не из своего конфига, а из
  `/api/settings` дашборда, чтобы настройки жили в одном месте. Отдаёт `/status` и `/events`
  на порту 3334 — их читает индикатор-глаз на дашборде.
- `ml_api/` — детектор. Это **вендоренная копия** `ml_api` из проекта
  [Obico (TheSpaghettiDetective)](https://github.com/TheSpaghettiDetective/obico-server),
  распространяемого под **AGPL-3.0**. Код чужой, авторство принадлежит проекту Obico;
  копия лежит здесь только ради предсказуемого развёртывания одним скриптом.
  Веса модели в репозиторий не входят — в `ml_api/model/` лежат лишь `.url`-ссылки на них.
- `run_ml_api.py` — наш запускатель для `ml_api`: перенаправляет вывод в `logs/ml_api.log`
  и стартует `server.py` без консольного окна. Сам `server.py` при этом не правим, чтобы
  копия оставалась сверяемой с апстримом.

## Чего здесь нет

`telegram_config.json` (токен бота и id чата), `events.json` и `logs/` исключены через
`.gitignore`. Токен не должен попадать в историю git даже на один коммит — удаление
следующим коммитом его не убирает, он остаётся в объектах репозитория и его придётся
отзывать. Файл создаётся локально:

```json
{ "bot_token": "...", "chat_id": "..." }
```

## Запуск

Отдельно запускать не нужно — `start-klippydash.bat` в корне поднимает дашборд, `ml_api`
и `watchdog.py` разом, все три без консольных окон. `stop-klippydash.bat` останавливает.
